# Tes fonds d'écran

Dépose ici les images que tu veux voir apparaître dans **Réglages → Apparence**.

- Formats acceptés : `.png` `.jpg` `.webp` `.avif` `.gif` `.svg`
- Elles apparaissent au rechargement de la page, sans redémarrer le serveur.
- Le nom du fichier devient le libellé de la vignette.

Ce dossier est git-ignoré : tes images restent chez toi et ne partent pas dans un
fork. Les douze fonds livrés avec l'app sont eux entièrement procéduraux
(SVG écrit à la main, dans `src/lib/wallpapers.ts`) — aucun asset binaire, aucune
question de droits pour qui clone le dépôt.
